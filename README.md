# 韻文時空館

臺灣國中國文課使用的平板優先互動網站。目前版本重製共用網站骨架與「詞館」前兩頁，內容依照專案根目錄的 `AGENTS.md` 與 `韻文時空館企劃書.md` 製作。

## 直接驗收

在 Finder 雙擊專案根目錄的 `啟動網站.command`，終端機顯示網址後，以 Safari 或 Chrome 開啟：

- 本機：`http://localhost:4173/`
- 同一網路的平板：終端機會列出可用的區域網路網址

關閉該終端機視窗，或按 `Control+C`，即可停止網站。

## 開發與建置

需求：Node.js 22.13 以上。

```bash
npm install
npm run dev
npm run typecheck
npm run lint
npm test
npm run build
npm start
```

Cloudflare Pages 的建置指令為 `npm run build`，輸出目錄為 `dist`。

## 目前驗收範圍

- 首頁以一條由左到右的時間線顯示「詩經、樂府詩、古詩、近體詩、詞、曲」。
- 詞館左上角保留由上到下的時間線，「詞」節點放大並發亮。
- 第一頁以點擊動畫呈現近體詩、外來音樂與詞的形成關係。
- 手機首頁使用垂直時間軸；觸碰詞館卡片只會點亮，須按「進入詞館」才切換頁面。
- 第一頁以低彩度唐朝地圖為背景，詩句格子只演示一次轉化並停在詞的長短句形狀。
- 第二頁以扭蛋抽詞牌、四格轉盤抽題目，再依代表體式逐句打字填詞。
- 完成作品須填寫自己的名字，再發佈到「汴京城佈告欄」；發布成功後佈告欄才展開，載入網站資料庫中的全班作品。
- 管理員以密碼進入佈告欄後，可逐篇刪除作品，也可自行設定並隨時更改管理密碼；新密碼儲存後立即取代舊密碼。
- 教師可由頁尾的管理入口以密碼驗證；初始密碼雜湊由網站執行環境提供，自訂後的密碼雜湊保存於網站資料庫。
- 詞牌池為虞美人、南鄉子、醜奴兒、如夢令、釵頭鳳；不混入曲牌「山坡羊」。
- 完成格式檢查後，草稿儲存在瀏覽器本機；不需登入。
- 全站頁尾標示：「本站由蘇牧盈老師發想設計，Codex協助製作。」
- 支援橫式平板、手機與桌機，並尊重系統的減少動態效果設定。

## 教師確認項目

- 各詞牌目前採一首代表作的句長作初階模具；同牌變體、平仄與押韻由教師後續帶領。
- 學生作品的上傳目的地與送出方式尚待教師指定。
