# 韻文時空館

臺灣國中國文課使用的平板優先互動網站。P0 已完成共用網站骨架與「詞館」，內容依照專案根目錄的 `AGENTS.md` 與 `韻文時空館企劃書.md` 製作。

## 直接驗收

在 Finder 雙擊專案根目錄的 `啟動網站.command`，終端機顯示網址後，以 Safari 或 Chrome 開啟：

- 本機：`http://localhost:4173/`
- 同一網路的平板：終端機會列出可用的區域網路網址

關閉該終端機視窗，或按 `Control+C`，即可停止網站。

## 開發與建置

需求：Node.js 22.13 以上。

```bash
npm install
npm run dev
npm run typecheck
npm run lint
npm test
npm run build
npm start
```

Cloudflare Pages 的建置指令為 `npm run build`，輸出目錄為 `dist-pages`。

## 教師確認項目

- 不同版本的字詞異文：如《蝶戀花・密州上元》的「此般／更無」、「乍入／卻入」。
- 《卜算子》的題名與正文異文：如「定惠／定慧」、「時見／誰見」。
- 小令、中調、長調採常見的 58／59 與 90／91 字界線；正式授課時可依採用教材版本調整措辭。
- 別名與體式只教國中共同核心，網站已在資料來源與範圍提示中標記教學界線。
